# Vue 3 企业级低代码平台

场景驱动型工程实践：通过 10 个真实核心场景，打通 Schema → Core → Runtime → Editor 的完整链路。

## 快速开始

```bash
corepack enable pnpm   # 首次
pnpm install
pnpm dev               # http://localhost:5173
pnpm test              # Vitest
pnpm typecheck
pnpm build
```
